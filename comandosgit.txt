COMANDOS DE BRANCH

Uma branch (ramificação) permite trabalhar em uma linha de desenvolvimento separada.

Listar branches locais:
	git branch

Mostra as branches locais do repositório. A branch atual aparece marcada com um asterisco (*).

Mudar para uma branch existente:
	git switch nome-da-branch

Substitua `nome-da-branch` pelo nome da branch para a qual deseja mudar. Por exemplo:
	git switch bug-fix

Criar uma branch:
	git branch nome-da-branch

Cria uma nova branch, mas mantém você na branch atual. Por exemplo:
	git branch bug-fix

Depois de criá-la, use `git switch bug-fix` para começar a trabalhar nela.

Caso queira criar e já mudar para a branch utilizamos o comando `git switch -c nome-da-branch`. Por exemplo:
    git switch -c bug-fix

Para mostrar as diferenças entre todos os arquivos não preparados e o ultimo commit utilizamos o 
    git diff

Para mostrar as diferenças entre um arquivo não preparado e o último commit utilizamos
    git diff index.html

Para mostrar as diferenças entre todos os arquivos preparados e o ultimo commit
    git diff --staged

Para mostrar as diferenças entre um arquivo preparado e o ultimo commit
    git diff --staged index.html

Para mostrar as diferenças entre dois commits usando hashes
    git diff 35f95fe 85fes9e

Para mostrar as diferenças entre dois commits usando head em vez de hashes
    git diff HEAD~1 HEAD~3

O git diff pode comparar duas branches diferentes
    git diff main bug-fix

Para renomear uma branch utilizamos o comando `git branch -m nome-da-branch novo-nome`
    git branch -m bug-fix bug-fix-responsividade

Para excluir uma branch utilizamos o comando `git branch -d nome-da-branch`
    git branch -d bug-fix
    
Caso ainda não exista a branch no meu github mas apenas no meu repositório local (git)
utilizamos o comando `git branch -D nome-da-branch`
    git branch -D bug-fix

Combinar ou mesclar branches

Para mesclar ou combinar uma branch com outra usamos o comando `git merge nome-da-branch`
Entretanto vale ressaltar que: É necessário estar na branch que você quer trazer a branch de destino
Ex: Quero trazer os arquivos da branch bug-fix para a main então é necessário que eu esteja
na branch main, para depois fazer o merge

Podemos fazer o marge sem estar na branch entretanto é necessário colocar a origem e o destino
    git merge bug-fix main
